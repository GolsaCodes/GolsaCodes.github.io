Information Retrieval System

Developed an LLM-based query expansion pipeline using the Gemini API to generate relevant expansion terms. Implemented and compared sparse and dense retrieval pipelines using BM25, BGE embeddings, and FAISS.

Evaluated the impact of query expansion on document retrieval using Recall@k, MRR@10, and nDCG@10.

Summer 2026

Movie Recommender System

Implemented a content-based recommender, experimenting with TF-IDF, Word2Vec, and Sentence-BERT to represent movie descriptions. I evaluated these text representations in terms of recommendation quality and computational efficiency. Ultimately, I observed that while classic approaches like TF-IDF executed faster, transformer-based models such as SBERT better captured context and delivered higher-quality recommendations. Later, I implemented Matrix Factorization to explore collaborative filtering and observed how user similarity affects recommendation quality.

Python Pandas NumPy NLTK Scikit-learn TF-IDF Word2Vec Sentence-BERT
